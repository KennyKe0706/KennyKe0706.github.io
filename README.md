# Kenny Ke — Personal Homepage

Personal academic homepage for Zixuan (Kenny) Ke.

## Live site

[kennyke0706.github.io](https://kennyke0706.github.io/)

## Stack

- React
- Vite
- JavaScript and CSS
- GitHub Pages

## Local development

```bash
npm ci
npm run dev
```

Build the production site with:

```bash
npm run build
```

Changes pushed to `main` are built and deployed through GitHub Actions.
